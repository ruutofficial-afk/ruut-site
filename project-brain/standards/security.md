# Standards — Security

## Frontend Security

### XSS Prevention
- Escape product titles before injecting into HTML:
  ```javascript
  const escapedTitle = product.title.replace(/'/g, "\\'");
  ```
- Never use `innerHTML` with raw user input
- Sanitize coupon code input before processing

### localStorage Safety
- Always wrap in try/catch (Safari private browsing can throw)
- Never store sensitive data (passwords, tokens, PII)
- Only store: cart items, coupon codes

### CORS
- All AJAX requests use `credentials: 'include'`
- WordPress session cookies must be sent with every request

## Backend Security

### Input Sanitization
Every POST parameter MUST be sanitized:
```php
intval()              // For numeric values
sanitize_text_field() // For string values
sanitize_email()      // For email addresses
```

### CORS Configuration
```php
// Verify origin header matches allowed domains
$allowed_origins = ['https://yourruut.com', 'https://www.yourruut.com'];
$origin = isset($_SERVER['HTTP_ORIGIN']) ? $_SERVER['HTTP_ORIGIN'] : '';

if (in_array($origin, $allowed_origins)) {
    header("Access-Control-Allow-Origin: $origin");
    header("Access-Control-Allow-Credentials: true");
    header("Access-Control-Allow-Headers: Content-Type, Authorization");
}
```

### WooCommerce Session Integrity
- Cart operations use WooCommerce's native session handling
- `cart_item_key` hashes are generated by WooCommerce (never by frontend)
- Coupon validation is performed server-side by WooCommerce

### Nonce Verification
For authenticated endpoints (OTP, account):
```php
wp_create_nonce('ruut_otp_nonce');
wp_verify_nonce($_POST['nonce'], 'ruut_otp_nonce');
```

## Security Checklist
- [ ] No raw user input in `innerHTML`
- [ ] All PHP inputs sanitized
- [ ] CORS origin whitelist enforced
- [ ] No sensitive data in localStorage
- [ ] Error messages don't expose server paths in production
- [ ] Try/catch wraps all AJAX handlers
