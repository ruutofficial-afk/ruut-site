#### Task:

2. Implement `getActiveVolumeDiscount()`:
   - Calculate volume tier discount amounts (e.g. ₹100 for 2 items, ₹250 for 3 items).

#### Verification Criteria for Loop 2:

### LOOP 3: Privilege Coupon, Loss Prevention & Mutual Exclusivity Engine

#### Task:
1. **Mutual Exclusivity Logic (Stacking Prevention)**:
   - When a coupon code is active (`activeCoupon !== ''`):
     - `updateGiftSimulation()` MUST remove all free gifts (`cart.filter(item => !item.is_gift)`).
     - `getActiveVolumeDiscount()` MUST return `0`.
     - Update progress banner text: `"Coupon {CODE} active. (Remove coupon to restore volume discount & free gifts)"`.
   - When a coupon is removed via `removeCoupon(code)`:
     - `activeCoupon` resets to `""`.
     - `updateGiftSimulation()` and `getActiveVolumeDiscount()` MUST immediately run, re-injecting earned free gifts and restoring volume tier discounts!
2. **Loss Prevention Confirmation Modal (`#ruut-confirm-overlay`)**:
   - `tryApplyCoupon(code)` checks if `activeCoupon` is set and different.
   - If active, display `#ruut-confirm-overlay` warning about benefit replacement.
   - On "APPLY ANYWAY", execute `executeApplyCoupon(code)`, trigger server sync (`ruut_apply_coupon`), update UI, and fire `triggerConfetti()`.

#### Verification Criteria for Loop 3:
- [ ] Applying coupon `TEST-12` removes all free gift items and zeroes volume discounts.
